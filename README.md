# Haram Travel

Next.js website for Haram Travel (UK Hajj & Umrah specialist).

## Stack

- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS v4
- Lucide icons

## Routes (SEO-aligned with existing WordPress slugs)

- `/` — Home
- `/about-us`
- `/contact-us`
- `/privacy-policy`
- `/umrah-packages`
- `/hajj-packages`
- `/december-umrah-packages`
- `/easter-umrah-packages`
- `/ramadan-umrah-packages`
- `/booking-form`

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
